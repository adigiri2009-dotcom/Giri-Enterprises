# GIRI ENTERPRISES V4
A GitHub Pages-ready business PWA prototype.

Features: premium splash animation, dashboard, CRM/khata structure, billing with GST/discount, printable logo invoice, inventory and serial passport, service/warranty, suppliers/purchases structure, cashbook, BI reports, targets/what-if simulator, solar sizing, local GIRI Brain, business settings and JSON backup.

## Deploy
Upload the contents of this folder to the repository root. Enable GitHub Pages from `main` / root.

## Note
This version is a front-end/local-first prototype. Production multi-device sync, authentication, payment gateways, WhatsApp APIs and server-side security require a backend.
